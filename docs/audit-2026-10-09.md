# Shadowrocket 规则集体检：2026-10-09

本次检查覆盖所有规则文件、转换器、自动更新流程、现有数据源及 Claude 新增数据源。
日期与维护记录按 Asia/Taipei 解读；机器报告保留上游时间戳的原始时区。
客户端为闭源软件，本次没有执行 iOS 客户端；兼容性结论限定为匹配类型、字段、
CIDR 和订阅格式的静态检查，以及公开规则源、开发者说明和用户提供的类型截图核对。

## 修复与新增

1. IPv4、IPv6 全部输出 `IP-CIDR`。原先 China IPv6 的 `IP-CIDR6` 已更新，
   GeoIP、ASN、Voice 三个生成器及校验器同步修复。网络集合不因类型修复改变。
2. 发布白名单只有 `DOMAIN`、`DOMAIN-SUFFIX`、`DOMAIN-KEYWORD`、
   `DOMAIN-WILDCARD`、`IP-CIDR`。拒绝 `AND`、`OR`、`NOT`、`DOMAIN-REGEX`、
   `SCRIPT`、嵌套规则和逐行策略。逻辑组合不属于本项目的后续计划。
3. 修复有限正则展开：不再将 `\b`、`\t`、控制字符、未知转义或反向引用
   当作普通字符输出。不能严格保留语义的规则会跳过并留下完整诊断。
4. 修复 AdGuard 例外证明：`#{0}`、`#{0,2}` 中的 `#` 可不出现，不能据此
   断言例外不匹配域名。无法安全表达的例外会阻止发布。
5. China/OpenAI 的 v2fly 转换启用严格模式。未知类型、畸形域名、未解析
   `include:` 和空结果阻止发布；不支持的正则保留为明确的覆盖缺口。
6. OpenAI 官方允许列表复核到 30 项。新增的
   `frontend-apps-multi-region.workos.com` 同时加入共享依赖排除表，
   保留 13 项默认路由子集。完整快照和默认分流边界保持可审查。
7. 新增 Claude 9 项域名规则和 AS399358 的 3 个网段，复用 OpenAI 下载的
   GeoLite2-ASN。提供普通版、`NoResolve` 版及独立来源子集。
8. 自动更新增加全文件校验、输入哈希与数据库版本报告、Claude 离线重建，
   以及诊断文件归档。拉取请求也执行测试和已发布规则的静态校验。

## Shadowrocket 类型与订阅格式

| 内容 | 本项目写法 | 核对依据 |
| --- | --- | --- |
| 精确主机名 | `DOMAIN,api.example.com` | 用户类型截图；开发者 App Store 的域名匹配说明 |
| 域名及子域名 | `DOMAIN-SUFFIX,example.com` | v2fly 自身类型定义与 Shadowrocket 原生规则样例 |
| 域名关键词 | `DOMAIN-KEYWORD,example` | 开发者 App Store 的关键词匹配说明 |
| 通配符 | `DOMAIN-WILDCARD,*.example.com` | 用户截图；App Store 2.2.65 的新增类型记录 |
| IPv4/IPv6 | `IP-CIDR,192.0.2.0/24` / `IP-CIDR,2001:db8::/32` | 原生 Shadowrocket LAN 列表与上游针对 IPv6 的修正记录 |
| IP 禁止额外解析 | `IP-CIDR,2001:db8::/32,no-resolve` | Shadowrocket 原生规则样例 |
| 导入规则集 | `RULE-SET,<URL>,<策略名>` | 上游 Shadowrocket 规则集使用说明 |

参考：[开发者 App Store 页面](https://apps.apple.com/ec/app/shadowrocket/id932747118?l=en)、
[当前 Shadowrocket LAN 原生列表](https://github.com/blackmatrix7/ios_rule_script/blob/master/rule/Shadowrocket/Lan/Lan.list)、
[IPv6 类型修正及维护者确认](https://github.com/blackmatrix7/ios_rule_script/issues/372#issuecomment-885345480)、
[原生 Claude 列表的 RULE-SET 使用说明](https://github.com/blackmatrix7/ios_rule_script/blob/master/rule/Shadowrocket/Claude/README.md)、
[v2fly 类型定义](https://github.com/v2fly/domain-list-community#syntax)。

订阅内容不包含策略列；策略由外部 `RULE-SET` 指定。只允许 IP 行的第三字段为
`no-resolve`。所有列表使用无 BOM 的 UTF-8、LF 和末尾换行，拒绝重复与空行。
包含通配符的列表要求 Shadowrocket 2.2.65 或更新版本。通配符不会擅自改成
后缀规则以扩大至根域名；正则也不会猜测改写成通配符或 URL 匹配。

## Claude 的域名与 IP 边界

域名来自 [v2fly 原始 Anthropic 列表](https://github.com/v2fly/domain-list-community/blob/master/data/anthropic)，
该文件的 [2026-10-02 更新](https://github.com/v2fly/domain-list-community/commit/2c892a618f4e23c549d28edd0f3f75407521b1aa)
证实其仍在维护。生成器每次固定一个当次提交，然后下载和转换，不永久锁定旧版本。
第三方 CDN 仅使用 `DOMAIN,servd-anthropic-website.b-cdn.net`，不会扩大到整个 CDN。

只显式追踪 **AS399358**。本次 GeoLite2-ASN 记录的组织为 `Anthropic, PBC`，
生成网段为：

```text
IP-CIDR,160.79.104.0/23
IP-CIDR,2607:6bc0:11::/48
IP-CIDR,2607:6bc0::/48
```

官方文档明确列出 `160.79.104.0/23` 与 `2607:6bc0::/48` 为 API 入站地址；
`2607:6bc0:11::/48` 来自同一 ASN 的当前数据库记录。这个集合表达已选 ASN
的目的地址分流范围，不保证覆盖 Claude 网页、客户端、API 的全部共享基础设施。
官方 `160.79.104.0/21` 是工具调用的出站来源地址范围，没有因此扩大目的匹配。
AWS、Google Cloud、Cloudflare 整个 ASN 均不加入 Claude。

## 验证结果与保留限制

完整执行更新工作流的下载与生成命令，成功生成全部来源与汇总规则。
Meta 与 Claude 的离线重建均检查了文件哈希。当前 28 个发布列表通过统一语法检查，
China、OpenAI、Claude 的汇总文件与各来源一致，所有普通/`NoResolve` 对等价。
单元测试覆盖转换、CIDR 地址族、错误输入、正则例外和缓存完整性。

本次明确保留 China 的 3 条不安全正则、OpenAI 的 1 条不安全正则，以及
AdGuard 无法安全映射的语法缺口；这些不是无声丢失，诊断会在构建归档中保留。
Voice IP 规则匹配整个目的网段，不限定端口和协议，以满足只使用基础类型的要求。
GeoLite2 的 ASN/地理数据可能落后于真实路由；本次 OpenAI AS401518 有一个前缀，
AS401864 没有数据库记录，保持报告这一事实，未凭空补入旧地址或共享云网络。

来源许可证继续分别适用，生成器保持 MIT。新增 Claude 域名来源为 v2fly MIT；
GeoLite 派生网段遵循其上游数据许可，未复制 blackmatrix7 的 Claude 派生列表。
